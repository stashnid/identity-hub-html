# IdentityHub

A responsive landing page for an online identity protection service, built with HTML, CSS, and a small amount of vanilla JavaScript.

**Frontend showcase:** dark visual design, animated interface mockups, and responsive layouts without a framework or build step. The page presents a service concept; it does not implement identity protection or payment processing.

## Highlights

- Hero section with an illustrated shield and floating information cards.
- Feature sections for data removal, identity cloaking, and support.
- Testimonials, pricing cards, and a monthly/yearly pricing control.
- Mobile navigation and layouts for desktop, tablet, and mobile screens.
- Inline SVG illustrations, gradient accents, shimmer effects, and hover states.
- Reduced-motion support through `prefers-reduced-motion`.

## View locally

Clone or download the repository and open [index.html](index.html) in a browser. No package installation is required.

The Manrope font loads from Google Fonts and requires an internet connection.

## Project structure

- [index.html](index.html) — page markup, inline SVG illustrations, and interaction scripts.
- [style.css](style.css) — layout, typography, animations, and responsive styles.

## Design

The interface uses a deep navy background (`#07071A`), soft glow effects, and warm gradient accents. Responsive breakpoints are defined at 1024px, 768px, and 480px.
