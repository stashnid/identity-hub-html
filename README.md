# IdentityHub — Static HTML+CSS

A fully static landing page for **IdentityHub** — an online identity protection service.

Built with pure HTML + CSS. No frameworks, no npm, no build tools.

## 🚀 Quick Start

Just open `index.html` in your browser — that's it!

```
open index.html
```

## 📁 Structure

```
identity-hub-html/
├── index.html   — Full page markup + inline SVG icons + minimal JS
└── style.css    — All styles, animations, responsive breakpoints
```

## ✨ Features

- **Hero** — Aurora glow, animated gradient text, shield visual with floating cards
- **Feature Removal** — Stack mockup with shimmer skeleton lines & AI badge
- **Feature Cloaking** — 6 credential cards in 2-column grid
- **Feature Support** — Chat mockup with avatar & reply button
- **Why Choose Us** — 3 info cards with interactive mockups
- **Testimonials** — CSS masonry layout (4 columns)
- **Pricing** — Yearly/Monthly toggle, featured card with gradient border
- **Footer** — Logo, link columns, social icons

## 🎨 Design

- Dark theme (`#07071A` base)
- Manrope font (Google Fonts)
- Gradient text & borders
- Shimmer animations
- Hover glow effects
- Responsive (1024px / 768px / 480px breakpoints)
- `prefers-reduced-motion` support
